# Word Dictation

### 只需要一支笔，一张纸，即可开始。

一个极简的批量背记与默写工具，适用于词汇、问答、概念、条文、代码和公式等内容。

**导入资料 → 显示提示 → 在纸上默写 → 查看答案 → 会的移出白名单 → 下一批。**

[下载 Android APK](https://github.com/RT-C-6668882025/word-dictation/releases/latest/download/word-dictation.apk)

</div>

## 词库与内容

- 新建、重命名和删除词库，支持直接粘贴或导入文件。
- 支持 TXT、JSON、CSV、TSV、Markdown、Excel、DOC、DOCX、PDF。
- 每条内容包含正面和背面，不限定语言、学科或固定字数。
- 支持多行文本，以及 Markdown 段落、列表、表格、代码块和公式。
- 导入时整理、去重；旧词库和已有标记保留。

## 背记与默写

- 保持分页、多条同时展示的形式，每条可独立显示或隐藏答案。
- 可显示正面、背面或全部，按批次练习。
- 每页默认 50 条，可设置为 10–200 条；每批数量可自定义。
- 短内容两面并列，长内容上下排列；隐藏答案时保留原位置。
- 代码、公式和表格超宽时，可在内容区域横向滚动。

## 白名单与索引

- 白名单保存需要继续背记的内容，会的移出，不会的留下。
- 支持单条或批量加入、移出，保留当前练习位置。
- 查看词库全部内容，搜索正面或背面，直接定位到所在页。
- 已移出的内容仍保留在词库中，可重新加入白名单。

## AI 连接

首次配对后，将固定 MCP 地址添加到支持远程 MCP 的 Agent，即可让 AI：

- 查看词库和内容。
- 按主题整理资料，创建或导入词库。
- 选择需要练习的内容，加入或移出白名单。
- 创建临时专题词库，沿用相同的背记方式。

无需电脑或 USB。配对地址长期保留，打开应用自动连接，断网后自动重连；所有页面显示连接状态，操作向 Agent 返回结果或失败原因。

Android 版支持后台执行指令，切换应用、锁屏后继续连接，通知栏显示状态；退出软件后停止连接。后台运行需要系统允许，网页版本需保持页面运行。

## 语音与保存

- Android 版支持系统语音和离线语音，可选择音色、语速，离线模型按需下载。
- 适配手机、平板及横竖屏，支持在应用内检查更新、下载安装包。
- 无需账号，词库保存在设备本地；不连接 AI 也可以独立使用。
- 正常覆盖更新保留词库，卸载或清除应用数据可能删除词库。
