# Word Dictation

### 只需要一支笔，一张纸，即可开始。

一个极简的批量背记与默写工具，适用于词汇、问答、概念、条文、代码和公式等内容。

**导入资料 → 显示提示 → 在纸上默写 → 查看答案 → 会的移出白名单 → 上滑下一页。**

## 词库与内容

- 新建、重命名和删除词库，支持直接粘贴或导入文件。
- 支持 TXT、JSON、CSV、TSV、Markdown、Excel、DOC、DOCX、PDF。
- 每条内容包含任意数量的内容块，不限定语言、学科或固定字数。
- 支持多行文本，以及 Markdown 段落、列表、表格、代码块和公式。
- 旧词库、页面和已有标记保留；Agent 编排的重复正文可作为独立条目。

## 背记与默写

- Android 使用原生竖向分页，页面跟随手指移动，松手后惯性翻页或吸附归位；网页支持连续分页吸附。
- 学习页统一上下滑动翻屏，每屏按内容高度与实际可用空间装入多条，不固定词数。原始词库页可以拆成多个刷页；每个内容块的显隐仍独立控制，页面配色不变。
- 轻触内容块本身即可在显示和隐藏之间切换。学习菜单可从左侧边缘向右划出，也可点左上角 ☰；向左划或点空白处收起。首页、索引、语音、范围筛选与重置显隐集中在菜单里。
- 长页面先在页内滚动阅读，到边界后的下一次滑动翻页。
- 一页可以放多条内容，由 Agent 指定页序、标题、条目、顺序和列数，窄屏自动单列。
- 不固定每页条数。Agent 为每个内容块独立设置初始显隐，并从自动、紧凑、阅读三种版式中选择；隐藏内容可逐块点击揭示。
- 保存阅读页，重新打开词库继续；支持按钮、键盘和鼠标滚轮翻页。
- 默认采用紧凑列表和细分隔线，短内容并排，长内容上下排列；不重复显示内容块编号和显隐标签。
- 多行文本、代码、公式和表格按统一规则排版，超宽内容可横向滚动。

## 白名单与索引

- 白名单保存需要继续背记的内容，会的移出，不会的留下。
- 支持单条或批量加入、移出，保留当前练习位置。
- 查看词库全部内容，搜索所有内容块，直接定位到所在页。
- 已移出的内容仍保留在词库中，可重新加入白名单。

## AI 连接

首次配对后，将固定 MCP 地址添加到支持远程 MCP 的 Agent，即可让 AI：

- 查看词库和内容，按关键词或编号查找。
- 重命名和删除词库，批量新增、修改或删除卡片。
- 合并、拆分词库，编排页面并保留白名单状态。
- 根据词库回答问题、解释和比较概念，标明内容出处。
- 根据词库逐题提问，对照答案反馈。
- 按主题整理资料，创建页面、安排多个独立内容块，并决定每块初始显示还是隐藏及页面版式。
- 选择需要练习的内容，加入或移出白名单。
- 创建临时专题词库，沿用相同的背记方式。

附件和原资料由 Agent 通过自己的云硬盘连接读取，整理后的背记内容通过 MCP 写入词库。

无需电脑或 USB。配对地址长期保留，打开应用自动连接，断网后自动重连；所有页面显示连接状态，操作向 Agent 返回结果或失败原因。

Android 版支持后台执行指令，切换应用、锁屏后继续连接，通知栏显示状态；退出软件后停止连接。后台运行需要系统允许，网页版本需保持页面运行。

## 语音与保存

- Android 版支持系统语音和离线语音，可选择音色、语速，离线模型按需下载。
- 适配手机、平板及横竖屏，支持在应用内检查更新、下载并打开系统安装器；保留安装结果详情及已下载安装包，支持失败后重试。
- 无需账号，词库保存在设备本地；不连接 AI 也可以独立使用。
- 正常覆盖更新保留词库，卸载或清除应用数据可能删除词库。
