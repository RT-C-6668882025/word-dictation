# Word Dictation

### 只需要一支笔，一张纸，即可开始。

一个极简的批量背记与默写工具。

**导入资料 → 显示正面或背面 → 在纸上默写 → 会的移出白名单 → 下一批。**

## 词库与导入

- 新建、重命名和删除词库
- 直接粘贴卡片，或导入 TXT、JSON、CSV、TSV、Markdown、Excel、DOC、DOCX、PDF
- 支持任意语言的正面与背面，整理并去重
- 导入后固定分页，默认每页 50 个，可自定义

## 默写

- 显示正面、背面或全部
- 一次显示 10 / 20 / 30 / 40 / 50 个，或自定义数量
- 每条内容可独立显示或隐藏答案
- 上一页、下一页，按批次练习

## 白名单

白名单就是需要背的内容。

- 单个或批量加入、移出白名单
- 会的移出，不会的留下
- 移出后打勾，再加入取消勾选
- 标记后保留当前位置，下拉刷新同步列表
- 可查看本页全部单词，找回已移出的词

## 单词索引

- 查看词库中的全部单词
- 搜索英文或中文
- 显示单词序号与所在页
- 点击直接定位到单词，或加入、移出白名单

## 语音

Android 版支持系统语音与离线语音，可选择音色和语速，离线模型按需下载。

## AI 连接

首次配对并复制固定 MCP 地址，即可添加到支持远程 MCP 的 Agent，无需电脑或 USB。以后打开应用自动连接，断网自动重连。

你可以让 AI：

- 查看现有词库和单词
- 随机选词，或按经济、旅行等主题选词
- 将选中的单词加入或移出白名单
- 将资料整理成中英词表并导入
- 创建临时专题词库，沿用原来的默写功能

所有页面都显示连接状态，执行指令时显示操作结果。每条指令向 Agent 返回成功数量或失败原因，超时后可按编号查询结果。

配对地址长期保留，只有解除配对才失效。Android 版在后台直接执行 AI 指令，切换应用、锁屏后继续连接，通知栏显示状态；退出软件停止连接。锁屏使用时，请允许系统后台运行。网页版本需保持页面运行。

## 使用与保存

- 手机、平板及横竖屏适配
- App 内检查更新、下载安装包
- 无需账号，词库保存在设备本地
- 不连接 AI，也可以独立使用全部默写功能
- 正常覆盖更新保留词库；卸载或清除应用数据可能删除词库

**拿起笔，开始默写。**

卡片不限语言和背记用途：词汇、问答、定义、条文、代码、公式都可以放在正面与背面。仍按原来的分页和多条列表练习，每条可独立显隐及加入白名单。旧词库自动兼容，内容和标记保留。

短内容支持两列 CSV、TSV、Markdown 表格；长内容推荐 JSON 文件或让 AI 通过现有导入工具提交 JSON 文本：

```json
[{"front":"什么是机会成本？","back":"选择一个方案时，放弃的最佳替代方案的价值。","format":"text"},{"front":"写出勾股定理","back":"$$a^2+b^2=c^2$$","format":"markdown"}]
```

`text` 保留原文换行；`markdown` 支持段落、列表、表格、代码块和公式。当前卡片内容为文本或 Markdown，不包含图片/音频附件存储。短条目两面并列，长内容占整行、两面上下排列；字号与间距统一；显隐保持位置，公式和代码超宽时在自身区域横向滚动。
