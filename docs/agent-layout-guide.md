# Agent 内容编排规则

应用固定一屏一条的竖向翻页、显隐操作、朗读、白名单及配色。Agent 只决定条目内容、块的顺序、初始显隐和版式，不写 CSS 或自定义交互。

## 选择版式

| layout | 使用场景 | 效果 |
| --- | --- | --- |
| `auto` | 不确定，或同一词库混合短句与长文 | 短块并排，长文自动上下排列 |
| `compact` | 单词、术语、短对应关系 | 最多三个短块并排；窄屏由应用调整 |
| `reading` | 概念解释、错题、代码、公式、多段 Markdown | 每块独占一行，按顺序阅读 |

## 编排内容块

1. 每个能独立显示或隐藏的内容必须是一个 block。不要把问题、提示和答案塞进同一块。
2. 按用户揭示的顺序排列 blocks。用 `initially_visible` 为每块指定初始状态；默认先显示提示或问题，隐藏答案。
3. 单词可以把英文、释义、联想和例句分成四块。反向回忆时可隐藏英文、显示释义，不需要重排按钮。
4. 知识点按“问题 → 线索 → 一句话答案 → 展开解释 → 例子”分层。不要为了增加块数拆碎一个完整句子。
5. 旧字段 `visible_count` 只为尚未设置 `initially_visible` 的块提供默认值。新内容尽量逐块显式指定。
6. 保留原有条目和块 ID，修改版式时只更新 `layout`，不要重新创建词库。

Agent 编排的是学习材料；用户上滑不代表掌握。白名单状态只能根据用户明确操作或要求改变。
