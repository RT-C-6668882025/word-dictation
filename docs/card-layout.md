# 卡片排版规则

展示形式仍是一页多条。每个条目包含编号、任意数量的内容块及白名单标记。

- 手机、平板上的短内容块并列；长内容与 Markdown 占完整列表行，内容块依次上下排列。普通短内容在宽屏上可两条并排。
- 内容块同字号、同行距（手机 16 px，其余 18 px；1.65 倍行距）。编号与白名单标记对齐条目顶部。
- 每个内容块按自身文本方向显示。正文完整显示、自然换行，保留原有段落；不根据长度缩小字号或截断。
- 显示与隐藏按钮位于内容块下方的操作行，首个内容块另有朗读按钮，操作区域互不重叠。
- Markdown 的标题、列表、段落采用统一间距，代码块、表格及公式在自己的区域滚动，不撑宽页面。
- 卡片展示为安全的文本/Markdown；不执行原始 HTML 或脚本，也不自动获取 Markdown 图片。图片与音频附件另行扩展。
- 原词库的英文/中文数据读为两个内容块，保留 ID、分页、白名单和历史操作回执。
