# 卡片排版规则

展示形式仍是一页多条。每个条目包含固定的编号、正面、背面及白名单标记。

- 手机、平板上的短条目，两面等宽并列；长内容与 Markdown 占完整列表行，正面在上、背面在下，各自使用完整阅读宽度。普通短内容在宽屏上可两条并排。
- 正反面同字号、同行距（手机 16 px，其余 18 px；1.7 倍行距），正面深色、背面灰色。编号与标记对齐条目顶部。
- 两面的阅读方向由各自文本决定，支持从右向左的语言。正文完整显示、自然换行，保留文本原有段落；不根据长度缩小字号或截断。
- 显隐使用固定区域，切换前后内容的位置、列宽和高度不变。
- Markdown 的标题、列表、段落采用统一间距，代码块、表格及公式在自己的区域滚动，不撑宽页面。
- 卡片展示为安全的文本/Markdown；不执行原始 HTML 或脚本，也不自动获取 Markdown 图片。图片与音频附件另行扩展。
- 原词库的英文/中文数据作为正面/背面读取，保留 ID、分页、白名单和历史操作回执。
